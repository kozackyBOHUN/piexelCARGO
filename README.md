# PixelCargo 0.1
Przeglądarkowy fundament gry transportowej. Obecny zakres: Faza I, bez mapy i mechanik transportu.

Wymagany Node.js 22.12+ (lub 20.19+) i npm. W katalogu repozytorium:

```sh
npm ci
npm run dev
npm test
npm run typecheck
npm run build
```

Dokumentacja: [roadmapa](docs/ROADMAP.md), [stan prac](docs/HANDOFF.md), [zakres Fazy I](docs/PixelCargo_Faza_I_Codex.md), [specyfikacja źródłowa](docs/SPEC_0_1_ORIGINAL.txt).
